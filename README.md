# Mod Patio — Luxury Outdoor Furniture
### Creative Direction: *"Golden Hour Living"*

Luxury outdoor furniture manufacturer based in Udaipur, India, supplying premium commercial-grade patio furniture to luxury resorts, boutique hotels, and hospitality brands.

🌐 **Live Website**: [https://ayush-tripathii.github.io/Mod-Patio/](https://ayush-tripathii.github.io/Mod-Patio/)

---

## 🎨 Creative Direction & Aesthetic
- **Concept**: *Golden Hour Living* — warm, optimistic, soft, and alive resort terrace at sunset.
- **Palette**: Dawn peach, apricot, warm cream, sunset terracotta, and leaf-green sustainability accents.
- **Typography**: Display serif *Fraunces* (variable font with SOFT axis) paired with modern UI font *Plus Jakarta Sans*.
- **Motion & Interaction**: Floating cut-outs on organic blob shapes, 3D flip cards, sticky scroll story, interactive category chips carousel, numbers counter animation, and smooth mobile bottom sheet navigation.

## 🛠️ Tech Stack & Standards
- **HTML5**: Semantic landmarks, Open Graph, Twitter Cards, Schema.org JSON-LD (@graph).
- **CSS3**: CSS Custom Properties (Variables), clamp fluid typography, 3D CSS perspectives, keyframes.
- **JavaScript**: Vanilla ES6+, IntersectionObserver API, requestAnimationFrame mouse-track parallax.
- **Accessibility**: Keyboard focusable flip boxes, ARIA attributes, `prefers-reduced-motion` compliance.
- **Performance**: Preloaded fonts and hero images, zero layout shift (CLS).
